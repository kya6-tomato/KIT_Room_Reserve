データを取り込む

使い方

画面

  • いまの状況 … 各部屋が使用中か空きか、残り時間・次の予定をひと目で確認できます。日付や時刻を変えると、その時点の状況になります。
  • タイムライン … 1日の全部屋の予定を横並びで表示します。
  • 部屋の時間割 … 部屋ごとの1週間の時間割。前後の週にも移動できます。印刷にも対応しています。
  • 空き部屋を探す … 日付と時間（時限ボタンでも可）を選ぶと、その間ずっと空いている部屋を一覧にします。
  • データ編集 … 予定の追加・修正、Excel / CSV / 貼り付けでの取り込み、Excel への書き出しができます。

データの入力方法

  • Excel … schedule.xlsx を編集してサイトに置くと反映されます。
  • 画面から … 「データ編集」で追加・修正し、「Excelに書き出す」でできた schedule.xlsx を置き換えます。
  • ファイル … .xlsx / .csv / .json を画面にドラッグ＆ドロップすると取り込めます。
  • 貼り付け … Excel や Googleスプレッドシートで表をコピーし、「データ編集」画面で Ctrl+V。
  • Googleスプレッドシート … config.js の dataSources に URL を書くと、スプレッドシートの内容を直接表示します。

曜日は「月」「月曜日」「月・水」「月〜金」「平日」、時間は「9:00」「9時半」「2限」「1-2限」「9:00-10:30」など、いろいろな書き方を読み取れます。日付を入れて内容を「休講」で始めると、その日の毎週の予定が取り消されます。
