# KIT_Room_Usage — 部屋使用状況

九州工業大学の部屋の使用状況を見ることのできるサイトです。
Excel（`schedule.xlsx`）に時間割を書いて置くだけで動く、サーバー不要の静的サイトです。

## できること

| 画面 | 内容 |
| --- | --- |
| **いまの状況** | 部屋ごとに「使用中 / まもなく / 空き」、残り時間、次の予定、1日の予定バーを表示。日付・時刻を変えるとその時点の状況に。お気に入り（★）の部屋は上に表示 |
| **タイムライン** | 1日の全部屋の予定を横並びで表示（現在時刻の線つき）。「時限の表」に切り替えると全部屋 × 1〜5限の一覧表に |
| **部屋の時間割** | 部屋ごとの1週間の時間割。前後の週へ移動、印刷、スマホでは一覧表示 |
| **空き部屋を探す** | 日付と時間（時限ボタンでも可）を選ぶと、ずっと空いている部屋・一部空いている部屋を一覧に。定員・建物で絞り込み |
| **データ編集** | 予定の追加・修正・複製・削除、取り込み、Excel / CSV / JSON への書き出し、読み取れない行や時間の重複の確認 |

そのほか: 時限ボタンで「3限の状況」をすぐ表示、部屋名から建物（講義棟・研究棟・その他）を自動で分類、時限ごとに分かれた連続コマ（3・4限の実験など）を1つにまとめて表示、部屋名・授業名・担当者での検索、ダークモード、大画面表示（入口のモニター向け、URL に `?kiosk=1`）、キーボードショートカット（`?` で一覧）、データの自動再読み込み。

## データの入れ方

1. **Excel** — `schedule.xlsx` の「時間割」シートを編集してサイトに置く（いちばん基本の方法）
2. **画面から** — 「データ編集」で追加・修正 →「Excel に書き出す」でできた `schedule.xlsx` を置き換える
3. **ファイル** — `.xlsx` / `.csv` / `.json` を画面にドラッグ＆ドロップ
4. **貼り付け** — Excel や Googleスプレッドシートで表をコピーし、「データ編集」画面で `Ctrl+V`
5. **Googleスプレッドシート** — `config.js` の `dataSources` に URL を書くと、スプレッドシートを直接表示（共有設定は「リンクを知っている全員」）

> 画面からの編集は **そのブラウザにだけ** 保存されます。みんなに反映するには、書き出した `schedule.xlsx` をサイトに置き換えてください。

### 時間割シートの書き方

| 部屋 | 曜日 | 日付 | 開始 | 終了 | 内容 | 担当者 | 備考 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 101教室 | 月 | | 9:00 | 10:30 | 情報基礎A | 山田 | |
| 101教室 | 月・水 | | 2限 | | プログラミング | 中村 | |
| 202教室 | | 2026/12/01 | 13:00 | 14:30 | 説明会 | | 臨時 |
| 101教室 | | 2026/12/07 | 9:00 | 10:30 | 休講 | | |

- 九工大の時間割のように **「部屋 / 曜日 / 時限 / 内容 / 担当者」** の5列（時限は 1〜5 の数字）でもそのまま読み込めます
- **曜日**: `月` `月曜日` `Mon` `月・水` `月〜金` `平日` など、いろいろな書き方を読み取れます
- **時間**: `9:00` `9時半` `午後1時` `0930` のほか、`2限` `1-2限` のような時限でも書けます。「時間」列に `9:00-10:30` とまとめて書いても OK
- **日付**: その日だけの予定。内容を「休講」「中止」で始めると、その日の毎週の予定が取り消されます
- 列の順番は自由で、`教室` `授業名` `担当` などの列名でも認識します
- 任意の **「部屋」シート**（建物・定員・備考・並び順）と **「時限」シート**（1限 = 8:50〜10:20 など）も使えます
- 内容が「⚠」で始まる行は「要確認」として、データ編集画面で目立つように表示します

読み取れなかった行は、「データ編集」画面に行番号つきで表示されます。

## 公開のしかた（GitHub Pages の例）

1. このリポジトリのファイル一式を、自分のリポジトリにアップロード
2. リポジトリの **Settings → Pages** で、Branch を `main`、フォルダを `/ (root)` にして保存
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で表示されます

ほかの静的ホスティング（Netlify、Cloudflare Pages、学内の Web サーバーなど）でも、ファイルを置くだけで動きます。
※ `index.html` をパソコンでダブルクリックして直接開いた場合は、ブラウザの制限で `schedule.xlsx` を自動では読み込めません（画面にファイルをドラッグ＆ドロップすれば表示できます）。

## 設定（`config.js`）

タイトル、読み込むデータ、自動更新の間隔、表示する時間帯、土日の列、時限の定義、部屋名から建物を決めるルール（`buildingRules`）などを変更できます。各項目に説明コメントがついています。

> 時限は九州工業大学（戸畑・飯塚の学部、2026年度の公式資料）の 1限 8:50〜10:20 … 5限 16:20〜17:50 に設定済みです。大学院の 6限（18:00〜19:30）を使う場合や時間が変わった場合は、`config.js` か Excel の「時限」シートを書き換えてください。

## ファイル構成

```
index.html          画面
config.js           設定
schedule.xlsx       時間割データ
assets/core.js      データ解析・時刻計算（画面に依存しない処理）
assets/app.js       画面の表示と操作
assets/style.css    デザイン
KIT_Room_Usage.html 以前の URL から index.html へ移動するためのページ
tests/core.test.js  core.js のテスト（node tests/core.test.js）
```

Excel の読み書きには [SheetJS](https://sheetjs.com/)（CDN から読み込み）を使っています。
